# Support

Rackio is preparing for its first supported release. The current source and
evaluation pre-releases are provided without a support commitment or response
time guarantee.

## Choose the right channel

- Report reproducible incorrect or degraded behavior with the
  [bug report form](https://github.com/genm/rackio/issues/new?template=bug-report.yml).
- Propose a new user outcome with the
  [feature proposal form](https://github.com/genm/rackio/issues/new?template=feature-request.yml).
- Report vulnerabilities only through
  [GitHub private vulnerability reporting](https://github.com/genm/rackio/security/advisories/new),
  following [`SECURITY.md`](SECURITY.md).

Search the README, operator documentation, and existing issues before opening a
new issue. Rackio does not currently operate a general question forum or offer
commercial support. If the public documentation is insufficient to reproduce or
diagnose behavior, open a bug report and identify the missing documentation.

Never include endpoint private keys, pairing bundles, live metric payloads,
routable addresses, or another person's private information in a public issue.
Sanitize logs, screenshots, packet captures, and machine-readable reports before
attaching them.

Release support status is authoritative in
[`docs/release-checklist.md`](docs/release-checklist.md). Closing an issue or
publishing an evaluation pre-release does not create a supported release line.
