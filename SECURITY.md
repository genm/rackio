# Security policy

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/genm/rackio/security/advisories/new).
Do not include endpoint private keys, pairing bundles, live metric payloads or
routable addresses in a public issue.

No release line is supported yet. The current tree is an implementation
preview; known blockers are listed in
[`docs/release-checklist.md`](docs/release-checklist.md).
